# Freelancer & Income Generation Engine

Local assistant for jobs, proposals, finance and approvals.

## What works offline

- Job storage and analysis (skill match, scam hints, suitability score)
- Proposal drafts
- Approval gate for external actions
- Earnings and fee calculator
- Dashboard section list
- Agent roles that only draft or analyze

## What is blocked

- Live Upwork / Fiverr / Freelancer.com / LinkedIn submission
- Payments
- Publishing

No platform credentials are stored in code. External actions stay blocked until an official API client is configured and the user approves the exact action.

Phase 6F generated-code execution remains blocked.
