# Report

1. Verdict — one line. Never "100% secure".
2. Counts — passed, fixed, still open, need you, skipped.
3. Open issues — Critical first, who fixes each.
4. To-do — open human checklist items.
5. Do this on live — Preview changes that must be repeated.
6. If a key leaks — revoke, update secrets, republish, check the bill.
7. Security contact — how issues are reported.
8. Clean up — delete AUDIT.md after fixes.
9. When to re-run — before major releases, after payments/uploads/AI, every 3 months.

End with: this catches common damaging mistakes, not a professional penetration test.
